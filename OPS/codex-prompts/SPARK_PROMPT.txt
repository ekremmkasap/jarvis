SLICE 5 — hey_jarvis.py: Persona voice identity + greeting
==============================================================

HEDEF:
Persona değiştiğinde (active_agent.json güncellenir) hey_jarvis.py:
  1. Yeni voice değerini okur
  2. TTS sesini günceller
  3. Persona greeting'ini sesli okur (SADECE BİR KEZ — debounce)

YAPILACAK:

A) Mevcut voice override kodunu bul. Çalışmıyorsa şu mantığı uygula:

   import json, time
   from pathlib import Path

   ACTIVE_AGENT_PATH = Path("state/active_agent.json")
   _last_greeted_persona = None
   _last_greeting_time = 0
   GREETING_DEBOUNCE_SEC = 4

   def get_active_persona_voice() -> str:
       try:
           data = json.loads(ACTIVE_AGENT_PATH.read_text(encoding="utf-8"))
           return data.get("voice", "AhmetNeural")
       except Exception:
           return "AhmetNeural"

   def maybe_play_greeting():
       global _last_greeted_persona, _last_greeting_time
       try:
           data = json.loads(ACTIVE_AGENT_PATH.read_text(encoding="utf-8"))
           persona_id = data.get("id", "jarvis")
           greeting = data.get("greeting", "")
           now = time.time()
           if persona_id != _last_greeted_persona and greeting:
               if now - _last_greeting_time > GREETING_DEBOUNCE_SEC:
                   _last_greeted_persona = persona_id
                   _last_greeting_time = now
                   # TTS ile greeting'i oku
                   speak(greeting)  # mevcut speak() fonksiyonunu kullan
       except Exception:
           pass

B) Polling loop içinde (varsa) veya her TTS öncesinde maybe_greeting() çağır.

C) Persona switch olduğunda "Jarvis'ten [name]'a bağlanıyorum" geçiş cümlesi:
   transition_text = f"Jarvis'ten {data.get('name', '')}a bağlanıyorum."
   speak(transition_text)
   (Bu da debounce kapsamında — greeting'den önce söylenir)

Oraya ekle:

   // persona rengi uygula
   if (data.color) {
     document.documentElement.style.setProperty('--persona-color', data.color);
   }

   const nameEl = document.getElementById('persona-name');
   const roleEl = document.getElementById('persona-role');
