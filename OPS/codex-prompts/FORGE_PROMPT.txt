SLICE 2 — server/bridge.py: LLM çağrısına system_prompt inject
==============================================================

bridge.py içinde LLM mesajı oluşturulan yeri bul (/api/chat veya eşdeğeri).
Orada şu mantığı ekle (backward-safe — Jarvis aktifse mevcut davranış korunur):

  from server.persona_manager import get_active_persona

  def _build_messages_with_persona(user_message: str, history: list) -> list:
      persona = get_active_persona()
      messages = []
      system_prompt = persona.get("system_prompt", "")
      if system_prompt and persona.get("id") != "jarvis":
          messages.append({"role": "system", "content": system_prompt})
      messages.extend(history)
      messages.append({"role": "user", "content": user_message})
      return messages

==============================================================
SLICE 3 — server/bridge.py: Obsidian komut entegrasyonu
==============================================================

bridge.py içinde gelen mesajda keyword detect et:

KAYDET triggerlari: "kaydet", "not al", "obsidian'a yaz", "bunu sakla"
  → from server.skills.persona_obsidian_skill import save_note
  → save_note(persona_id=active_id, title=ilk_cümle, content=mesaj)
  → Kullanıcıya: "Obsidian'a kaydedildi: [başlık]"

RECALL triggerlari: "ne biliyorsun", "araştırdıklarımız", "notlarına bak", "geçmişte"
  → from server.skills.persona_obsidian_skill import recall_notes
  → notes = recall_notes(persona_id=active_id, query=mesaj)
  → LLM messages'a context olarak ekle: {"role": "system", "content": f"Obsidian notların:\n{notes}"}

TELEGRAM KOMUTLARI (bridge.py içine):
  /obsidian-kaydet <başlık> → save_note() çağır
  /obsidian-oku <query>    → recall_notes() çağır, sonucu Telegram'a gönder
