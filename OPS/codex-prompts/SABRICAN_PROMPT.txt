GÖREV — Sabrican DevOps Skill Katmanı
==============================================================

A) server/skills/sabrican_ops_skill.py oluştur:

1. check_service_health(service_name, url=None):
   - Bilinen servisler: "bridge" (localhost:8081/health), "ollama" (localhost:11434), "hologram" (electron process)
   - URL verilirse o URL'e GET atar, timeout 5 sn
   - Process kontrolü: psutil ile process adına göre (psutil yoksa subprocess ile tasklist)
   - {"ok": True/False, "service": str, "status": "up"|"down"|"unknown", "latency_ms": int|None} döner

2. get_system_status():
   - Tüm bilinen servisleri kontrol et (bridge, ollama, hologram)
   - CPU %, RAM %, disk % (psutil varsa, yoksa subprocess ile wmic)
   - {"services": list, "cpu_pct": float, "ram_pct": float, "disk_pct": float} döner

3. docker_status():
   - `docker ps --format json` subprocess çağrısı
   - Docker yoksa veya çalışmıyorsa graceful fail
   - Çalışan container listesi döner

4. restart_service(service_name):
   - Sadece "bridge" ve "ollama" destekler (güvenli liste)
   - bridge: bridge.py process'ini yeniden başlat
   - Diğerleri → {"ok": False, "error": "not_allowed"}
   - Her restart server/logs/sabrican_ops.jsonl'e loglanır

B) server/bridge.py içine Telegram komutları ekle:

- /sabrican-durum           → get_system_status() çağır, formatlı özet
- /sabrican-servis <isim>   → check_service_health() çağır
- /sabrican-docker          → docker_status() çağır
- /sabrican-restart <isim>  → restart_service() çağır (sadece whitelist)
