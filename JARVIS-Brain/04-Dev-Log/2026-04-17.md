## POC Roadmap (Integration Candidates)

### VibeVoice (Microsoft) — Voice Upgrade
- Hedef: `hey_jarvis.py` STT/TTS katmanı
- Özellik: 60dk transkript, speaker diarization, 50+ dil, streaming
- Entry point:
  ```
  external-repos/VibeVoice/  (git clone)
  → voice/vibevoice_adapter.py (yeni — Piper yerine çalışacak adapter)
  → hey_jarvis.py line where TTS_PROVIDER okunuyor
  ```
- Komut POC: `/voice-test vibevoice "merhaba jarvis"`
- Branch önerisi: `009-vibevoice-integration`
- Tahmini süre: 2-3 saat (model indirme + adapter)
- Risk: model boyutu ~5GB, lokal GPU gerekiyor olabilir

### Octogent (hesamsheikh) — Claude Code Orchestration
- **Not:** Node.js (Python değil!) — `swarm_skill.py`'in *yerine* değil *üstüne*
- Kavramlar: Tentacles (scoped job folders), todo-driven delegation, inter-agent messaging
- Kullanım modeli: tek Jarvis komutu → birden fazla paralel Claude Code session spawn
- Entry point:
  ```
  external-repos/octogent/  (pnpm install && pnpm build)
  → server/skills/octogent_bridge.py (yeni — subprocess wrapper)
  → /octogent spawn <task> komut handler
  ```
- Branch önerisi: `010-octogent-orchestration`
- Bağımlılık: Node 22+, `claude` CLI (zaten var)
- Fark: OpenAI Swarm function-calling değil; file-state üzerinden koordinasyon
- İlk POC: `/octogent-spawn "3 farklı skill dosyasını paralel refactor et"`

### Graphify — Token Optimization
- Hedef: `server/skills/agent_memory_skill.py` ve `state/agent_memory/<id>/`
- Pattern: conversation history → knowledge graph → 70x token tasarrufu (iddia)
- Entry point:
  ```
  server/skills/agent_memory_graph_skill.py (yeni)
  → agent_memory_skill retrieve() fonksiyonuna graph-aware layer
  → state/agent_memory/<id>/graph.json yeni dosya
  ```
- Branch önerisi: `011-graphify-memory`
- Tahmini süre: 1 gün (graph schema + retrieval + benchmark)
- Test: aynı conversation'da token sayısı A/B

### OpenGuider (mo-tunn/OpenGuider) — Desktop UI Agent Pattern Study
- Repo: `github.com/mo-tunn/OpenGuider` v0.2.2 · Electron + Node.js
- Yazar: Metehan Kızılcık (@mo_tunn1, TR dev, 5.5K IG takipçi)
- **Kategori:** Mark-XXXV ile aynı kulvar — desktop AI assistant, screenshot + pointer guidance
- **Library değil** — standalone app, embed edilemiyor
- **Pattern extraction değerli olan 2 şey:**
  1. **Coordinate pointer hints**
     - Screenshot → LLM vision → `{x, y, action: "click|type|scroll"}` JSON
     - Hedef dosya: `external-repos/Mark-XXXV/actions/vision_controller.py` (yeni)
     - Integration point: `computer_agent_skill.py` → `/bak` yanıtı koordinat eklesin
  2. **Planner replanning loop**
     - Çok-adımlı task: plan → execute → verify → replan
     - Hedef dosya: `server/skills/task_planner_skill.py` (yeni)
     - Integration: `/yap <karmaşık görev>` → çoklu adım + her adımda state verification
- Branch önerisi: `013-coordinate-vision-planner`
- Provider uyumu: Claude/Gemini/Groq/Ollama hepsi destekliyor (bizimle aynı stack)
- Tahmini süre: 1 gün (sadece 2 modül port, clone-install değil)
- Karşılaştırma notu: bizde **persona sistemi + TR voice + OpenClaw** var, onda yok → overlap değil complement
