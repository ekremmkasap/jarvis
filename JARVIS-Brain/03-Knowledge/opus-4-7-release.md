# Claude Opus 4.7 — Release Notları

Anthropic'in en yeni modeli. Jarvis Mission Control'da aktif.

## Model ID
`claude-opus-4-7`

## Yeni Özellikler
- **Stricter instruction following** — prompt'a daha sıkı bağlı kalıyor
- **Better vision** — image/screenshot anlama gelişti
- **xhigh effort mode** — derin düşünme, karmaşık görevler
- **Fast mode** — Opus 4.6 ile hızlı çıktı (downgrade değil)

## Claude 4.X Model Ailesi
- **Opus 4.7** — `claude-opus-4-7` (bu)
- **Sonnet 4.6** — `claude-sonnet-4-6`
- **Haiku 4.5** — `claude-haiku-4-5-20251001`

## Knowledge Cutoff
Ocak 2026

## Jarvis İçin
- Claude Code v2.1.111 + Opus 4.7 xhigh şu an kullanımda
- `config/model_router.yml`'de "claude" tier'ı bu modele yönlenir
