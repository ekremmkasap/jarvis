================================================================================
                              COMMAND USAGE
================================================================================

opencode serve --port 7080          # Start OpenCode server
opencode skills --list              # List all available skills
opencode skills --search [keyword]  # Search skills
opencode skills --info [skill]      # Get skill details

From Jarvis:
/opencode-skills [category]
/opencode-skill [skill-name]
/opencode-run [skill] [args]

Examples:
/opencode-skills marketing
/opencode-skill social-media-manager "Instagram strategy for dogs"
/opencode-skill autoresearch-agent "Telegram throughput optimization"
