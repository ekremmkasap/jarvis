## Integration with Jarvis Ecosystem

### Bridge.py Endpoint: `/sabri/generate-ad-strategy`

```python
@app.post("/sabri/generate-ad-strategy")
async def generate_ad_strategy(brand_name: str, product: str):
    """
    Sabri persona ad creative strategy generator
    (Replicate @alexlindai's workflow)
    """
    # Step 1: Voice of Customer research
    voc_data = await mert.research_customer_voice(brand_name, product)
    
    # Step 2: Brand DNA analysis
    brand_dna = await seda.build_brand_dna_document(brand_name, voc_data)
    
    # Step 3: Generate 40 ad prompts
    ad_prompts = await generate_40_ad_concepts(voc_data, brand_dna)
    
    # Step 4: Package as deliverable
    strategy = {
        'brand': brand_name,
        'voc_insights': voc_data,
        'brand_dna': brand_dna,
        'ad_prompts': ad_prompts,
        'ready_for': ['Meta', 'TikTok', 'Instagram', 'Google'],
        'estimated_ctr_lift': '25-35%',
        'estimated_cost_reduction': '40-50%'
    }
    
    return strategy
```

- `ad_voc_research.py` — Mine customer language from reviews + forums
- `brand_dna_generator.py` — Create visual + tonal guidelines
- `ad_prompt_generator.py` — Create 40 distinct ad prompts
